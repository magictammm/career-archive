# 03 · 框架页规范

## 目标

把「项目台账 + 深挖文档」合成**一个单文件自包含 HTML**：双击可开、离线可用、无外部依赖、点击条目看全文。

## 页面结构

```
标题区（项目数 / 周期 / 公司）
TOC（三个锚点）
① 整机与硬件   甘特，纵轴＝价格档
② 软件与平台   甘特，纵轴＝形态分层（PC / 移动 / 云 / 设备端）
③ 页脚         字段与口径说明、图例
弹层           文档全文 + 多文档 tab
```

## 坐标公式

以 config 的 `start` 为原点，`origin` = 年×12 + 月−1。

```
months   = (end 月序号) − (start 月序号) + 1
COL_W    = (VIEW_W − PL − PR) / months          // PL=96 左轴标签区, PR=24
x(i)     = PL + i × COL_W
xEnd(i)  = PL + (i+1) × COL_W
条宽     = xEnd(endIdx) − x(startIdx)，最小 6px
```

硬件区（价格轴）：

```
maxK   = ceil(max(所有 price))
plotH  = maxK × PX_PER_K                        // PX_PER_K 默认 74
y(price) = YEAR_H + (maxK − price) × PX_PER_K   // YEAR_H=34
条 top   = y(price) − BAR_H/2                   // BAR_H=26
```

软件区（形态轴）：

```
LAYER_H = 48
层中心 y(i) = YEAR_H + i × LAYER_H + LAYER_H/2
```

## 条形避让

价格相近且时间重叠的项目会叠在一起，必须自动避让：

1. 按 start 升序排（同 start 时长的排前）。
2. 逐条检查：若与已放置条的时间区间重叠（留 4px 容差）且纵向距离 < BAR_H + GAP，则 `top = 冲突条.top + BAR_H + GAP`，循环直到无冲突（上限 40 次）。
3. 最后夹到绘图区内 `top ≤ H − BAR_H − 6`，防止溢出卡片。

软件区同理，间隔用 BAR_H + 2。

## 窄条自适应

条宽 < 168px（软件区 150px）时：

- 系统 pill 与价格隐藏，日期下沉到第二行。
- `.nm` 必须 `flex:0 0 auto` + `max-width` + `ellipsis`，否则永远撑开。
- 日期 `.dt` 必须 `flex:1 1 auto` + `min-width:0`，否则不收缩、会和相邻元素重叠。

## 交互

- 条目带 `data-open="1"` + `data-key` → 可点击；无文档的条目只渲染 `todo` 类（虚线 + 降透明度 + 「暂无文档」），**不可点**，也不留空位。
- 弹层：`#mask` 遮罩 + `#panel` 面板；`Esc` / 点遮罩 / × 关闭。
- 一项目多文档 → 头部渲染 tab，`MAP[key]` 为数组，顺序即 tab 顺序。
- 悬停提示「查看深挖 →」用 `::after` 绝对定位 + `pointer-events:none`，**不要**用 `padding-right` 挤占布局（会压掉第二行文字）。

## 内嵌文档的注意事项

```js
DOCS[file] = md.replace(/<\/script/gi, '<\\/script')
                .replace(/\u2028/g, '\\u2028')
                .replace(/\u2029/g, '\\u2029');
```

- 不转义 `</script` 会让文档里的代码块截断整个 script 标签。
- JSON 内嵌后浏览器端直接 `JSON.parse` 语义使用，不要再拼字符串。

## 渲染器

页面内置轻量 markdown 渲染器（约 120 行，零依赖），支持：标题 / 表格 / 引用 / 有序无序列表 / 任务列表 / 粗体 / 行内代码 / 链接 / 代码块 / 分隔线。
不支持嵌套列表的深层缩进，深挖文档里避免三层以上嵌套。

## 已踩过的坑

| 现象 | 原因 | 处理 |
| - | - | - |
| 年份色块压穿页脚 | 软件区复用 `.col{height:700px}` 硬编码 | 给软件区独立高度变量，别复用带固定高度的列 |
| 窄条里文字与日期重叠 | `.dt` 缺 `flex-shrink`，`.nm` 不限制 max-width | `.dt{flex:1 1 auto;min-width:0}` + `.nm{max-width:min(58%,300px)}` |
| 坐标缺失的元素跑到左上角 | 数据数组里有空坐标项，生成 `left:undefined` | 生成前过滤空项，或用默认值兜底 |
| 正则替换后条数量骤减 | 非贪婪 `([\s\S]*?)</div>` 只吃到第一层 | 用明确的终止锚点（如 `<div class="l2">…</div></div>`） |
| `&amp;` 型号名匹配不到 | HTML 实体已转义 | 按出现顺序索引绑定，不靠文本匹配 |
| 徽标插入后页面乱码 | `String.replace` 里 `$&` 被当替换模式 | 用 `indexOf` + `slice` 精确拼接，或用函数式 replace |

## 验收清单

- [ ] 单文件打开无外网请求
- [ ] 可点击条数 = 有文档的项目数
- [ ] 每个弹层能显示对应文档全文，无「文档缺失」
- [ ] 最窄的条文字不溢出、不重叠
- [ ] 所有条都在卡片绘图区内（截图检查上下边界）
- [ ] 两个区的时间轴上下对齐

## 附：非硬件岗位的轴映射（通用化）

本文件写的坐标公式与样式对**任何轴**都成立，变的只是「纵轴代表什么」。硬件岗用价格带，其他岗位按下表换掉 `price` / `layer` 的语义即可：

| 岗位族 | 主区纵轴（原 price 轴） | 支撑区纵轴（原 layer 轴） | 备注 |
| - | - | - | - |
| 硬件 / 智能设备 | 价格带（k） | PC 端 / 固件 / 云端 / 移动端 | 原设计场景 |
| 软件 / SaaS | 模块或业务域（用序号代替价格） | 端（Web / App / 后台 / 开放平台） | 价格字段换成模块权重 1–10 |
| BA / 需求分析 | 需求类型（资金 / 交易 / 内容 / 合规） | 交付批次（PI / 版本） | 纵轴分层数 4–6 最合适 |
| 研发 | 系统分层（接入 / 服务 / 存储 / 端侧） | 技术栈或迭代线 | 可用「复杂度 1–10」代替价格 |
| 运营 / 增长 | 渠道（私域 / 公域 / 内容 / 投放） | 活动或内容矩阵 | 条长＝活动周期 |
| 销售 / BD | 客户行业或客单价档 | 客户分层（KA / 中小 / 长尾） | 条长＝跟进周期 |
| 设计 | 产品线 | 端或设计系统 | |
| PMO | 项目组合 | 阶段（立项 / 开发 / 交付） | |

实现方式二选一：
1. 手写骨架里的 gantt 结构（项目数 < 10 时更快，见 `assets/whitepaper_skeleton.html`）。
2. 复用 `build_framework.cjs`，把 `price` 传成该轴的序号值（1–10），`system` 传轴标签；坐标逻辑不用改。

**不要**为了套公式去编价格——轴对不上时宁可用序号，也不要写假数字。
