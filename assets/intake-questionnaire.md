## 我要做一份《个人职业档案白皮书》

它不是简历，是**底档**：把你这些年的经历拆成「公司 → 项目 → 我做了什么 → 结果」，再连成职级 / 职责范围 / 业务复杂度 / 团队规模 / 影响力五条曲线，配薪资变化。以后求职、晋升、述职、复盘都从这份底档里取料，不用每次重写。

流程四步，你只需要配合前三步：

1. 你回答下面 A、B、C 三部分（不确定的写「不确定」就行）
2. 我逐项目提 3–5 个追问，你口述即可，不用写文档
3. 你把手上的原始资料给我（有多少给多少）
4. 我产出：单文件 HTML 白皮书 + 每个项目的深挖文档 + 待补清单

---

### A. 六个基础问题（必答）

**A1 目标岗位**：现在做什么岗？下次想投什么岗？
> 示例：现在做软件产品经理，想投硬件产品经理

**A2 行业与业务**：什么行业、卖给谁？
> 示例：智能影像设备，B2C 出海为主，少量 B2B 渠道

**A3 公司体量与位置**：公司多少人、你所在部门几个人、向谁汇报？
> 示例：公司 800 人，产品部 12 人，向产品总监汇报

**A4 你交付的东西**（可多选）：代码 / 需求文档 / 设计稿 / 内容 / 客户 / 合同 / 报表 / 计划与里程碑 / 其他？
> 示例：需求文档 + 原型 + 版本排期

**A5 协作半径**：带不带人？跨几个部门？对接外部供应商吗？
> 示例：带 2 人小组；跨研发、供应链、市场 3 个部门；对接 4 家方案商

**A6 这份档案先解决什么**：求职 / 晋升答辩 / 述职 / 年度复盘 / 纯归档？
> 示例：求职，目标是年中跳槽

### C. 手上的资料（有什么给什么，没有就跳过）

- [ ] 旧简历（几个版本都给，我会比对差异）
- [ ] 绩效评估 / 年度总结 / 述职材料
- [ ] 周报、月报、季度总结
- [ ] 项目立项书、需求文档、版本发布记录
- [ ] 组织架构图 / 团队名单

## 收到回答后的处理

| 情况 | 处理 |
| - | - |
| A4 答得多而杂 | 取出现频率最高的那类作主族，其余作辅助能力 |
| A1 与 A4 冲突 | 以 A4 为准，A1 写进「目标岗位」用于定制 |
| B 只填了 1–2 段 | 先做这两段，出骨架版给用户看，再逐个补 |
| C 全空 | 不阻塞，用口述追问补；标 `口述` 来源 |
| 薪资拒答 | 薪资章隐藏，不占位、不追问第二次 |
